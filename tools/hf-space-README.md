# Payment Intelligence — live demo

Analyst portal for AI-powered financial crime detection, built on Boomi Integration, Boomi Agent Garden and Neon PostgreSQL.
Every request goes to the real Boomi runtime. Analyze, Transfer and Assistant calls are rate-limited per visitor.

Source code and documentation: https://github.com/hadisaputrap16-ops/payment-intelligence

Space secrets required: `PI_BOOMI_BASE_URL`, `PI_BOOMI_USER`, `PI_BOOMI_TOKEN`, `SNAP_PARTNER_PRIVATE_PEM`, `SNAP_BOOMI_PUBLIC_PEM`.
